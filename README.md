# Growlauncher

Simple launcher app with a **Launch** button that starts a local Growtopia clone executable.

## Run

```bash
python /home/runner/work/Growlauncher/Growlauncher/Ching791/Growlauncher/launcher.py
```

By default the launcher targets:

- Windows: `GrowtopiaClone.exe` in the project folder
- Other OS: `growtopia-clone` in the project folder

You can override the target path with:

```bash
GROWTOPIA_CLONE_PATH=/absolute/path/to/clone python /home/runner/work/Growlauncher/Growlauncher/Ching791/Growlauncher/launcher.py
```
